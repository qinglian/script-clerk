# 场记软件 (Script Clerk)

一款专为影视拍摄现场设计的场记管理工具，助你高效记录每个镜头的拍摄信息。

## ✨ 功能特性

### 📊 统计概览
- 场景数、镜头数、总条数统计
- 通过率、NG率、补拍率可视化
- 进度条直观展示

### 📋 场记记录管理
- 新建/编辑/删除场记记录
- 支持按场景号、镜头号搜索
- 按状态筛选（通过/NG/补拍）

### 📝 场记信息字段
- **场景信息**: 场景号、内/外景、日/夜景、场景描述
- **镜头信息**: 镜头号、机位、条数
- **拍摄信息**: 状态、导演备注、摄影备注
- **演员信息**: 参演演员
- **时间信息**: 日期、开始/结束时间

### 📤 数据导出
- **Markdown 格式**: 适合阅读和打印
- **CSV 格式**: 适合 Excel 分析

### 💾 数据存储
- 使用浏览器 localStorage 存储
- 无需后端，纯前端应用
- 数据持久化保存

## 🚀 快速开始

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

访问 http://localhost:5173 开始使用。

### 构建生产版本
```bash
npm run build
```

## 📖 使用说明

### 1. 创建项目
首次使用需要创建一个项目，填写项目名称、导演和场记信息。

### 2. 新增场记记录
点击"新增记录"按钮，填写场记信息：
- 必填：场景号、镜头号、日期
- 选填：场景描述、机位、条数、状态、备注等

### 3. 查看统计
在"统计概览"页面查看拍摄进度和各状态分布。

### 4. 导出数据
在"导出数据"页面选择格式导出，支持 Markdown 和 CSV。
